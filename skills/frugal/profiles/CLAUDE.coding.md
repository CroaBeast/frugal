# Coding profile
# Ponytail (plugin) already enforces: simplest solution, no unrequested abstractions, no speculative features, stdlib first. Do not restate those here.

## Output
- Code first. Explanation after, only if non-obvious.
- Comments only where logic is unclear.
- No boilerplate unless requested.
- Code output copy-paste safe: plain hyphens, straight quotes.

## Code rules
- No docstrings or type annotations on code not being changed.
- No error handling for scenarios that cannot happen.

## Review
- State the bug. Show the fix. Stop.
- No suggestions beyond review scope. No compliments.

## Debugging
- Never speculate about a bug without reading the relevant code first.
- State what you found, where, and the fix. One pass.
- If cause is unclear: say so. Do not guess.
